## 一、它是什么

**CatHome4 是一个本地运行的 AI 工作站。** 它把大模型变成一群能自己干活的「猫」——每只猫有人格、有工具、有自己的记忆，能在你的电脑上读写文件、写代码、查网页、看图片、执行命令，并在一个对话界面里把全过程展示给你。

宿主常驻桌面（Windows 托盘，Linux 走 systemd），数据全部留在本机。它不是一个聊天窗口，是一个**能持续干活的工作台**。

| 能力 | 一句话 |
|:--|:--|
| **多猫并行** | 一进程跑多只猫——各自人格、工具面、配置、会话互不干扰 |
| **全工具面** | 文件 / 代码 / 终端 / 网页 / 图像 / 数据 —— 猫真能动手，不是只会聊天 |
| **有据可查** | 每一步工具调用、每一次回复过程都在界面里可见；日志帧号可回溯 |
| **多通道** | 浏览器面板 · QQ（@ 收信 / 群留档 / 主动发言）· HTTP 通道（外部程序注入 / 群播报） |
| **自我成长** | 业务逻辑用自研方言 Mau 表达，改完热重载即生效，不重启 |

**技术栈：** C# / .NET 10（跨 Windows 与 Linux）· 直连 LLM API（自填端点与密钥，无中间平台）· Roslyn / TS 语法树工具 · 原生 HTML / JS / CSS（零框架）· 自研方言 Mau 表达全部业务。

## 二、快速上手

**前置：** Windows 或 Linux + **.NET 10 SDK**（`dotnet --version` ≥ 10.0）。

```bash
git clone git@gitee.com:wu_lisha/mau.git
cd mau
```

> GitHub 镜像：`https://github.com/WuLiSha-HUB/mau.git`（自动同步）

**四步跑起来**（`SetUp.exe` 须放在仓库根，同目录要能看到 `Mau.sln`）：

```bash
SetUp.exe prepare                    # ① 全链构建：编译 → 测试 → 编译语料 → 发布（~35s）
SetUp.exe deploy C:\MauTest\MauOut   # ② 发布正式运行实体到【仓库之外】的目录
C:\MauTest\MauOut\CatHome4.exe       # ③ 双击启动（宿主常驻托盘）
# ④ 浏览器打开 http://127.0.0.1:8080 → 设置访问口令 → 填入 LLM 端点与密钥
```

🔴 **必须部署到仓库之外**——部署目录是正式运行实体，与仓库解耦；此后重建或删除仓库都不影响它。

托盘图标：左键开控制台，右键可开机自启 / 打开数据目录 / 退出。关掉控制台窗口 ≠ 退出。

**更新：** 改完源码 `SetUp.exe prepare` → 经宿主控制台重启（零停机前置，验证不过则保持原版本运行）。

> 完整流程（含 Linux 部署链、重启三档、口令与认证、观测与排错）→ **[07 宿主与部署](docs/manual/07-host.md)**。

## 三、数据与隐私

- **数据全在本机**——配置、会话、日志都在数据目录；正式实例的数据与源码仓库严格分离。
- **密钥单独存放**（`secrets/`）——不进对话、不进快照、不进日志。
- **访问口令**：主端口可设口令，令牌只存浏览器内存，刷新即重输。
- **运行日志按次落盘**（帧号可追溯）——出问题能回看每一步。

数据目录：`%LOCALAPPDATA%\CatHome4\Data`（Windows）· `CH4_DATA_ROOT` 指向处（Linux）。
