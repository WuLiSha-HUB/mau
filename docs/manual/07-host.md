# 07 · 宿主与部署

> 宿主 = CatHome4 进程。本章讲它怎么跑、数据在哪、怎么观测、怎么部署与重启。

## 运行形态

- **GUI 外壳（WinExe）**——不启前台控制台窗口。三层线程：runtime（Main·进程生命线）/ 任务栏 UI（托盘常驻）/ GUI（总控窗·按需起停）。
- **托盘常驻**：左键开控制台；右键菜单——开机自启 / 打开数据目录 / 显示控制台 / 退出。关掉总控窗 ≠ 退出（托盘图标仍在）。
- **端口**：管理面板（部署区 `8080` / 开发区 `8079`）；每猫对话页独立端口。端口单例——同区占用即报错。
- **端口分区**：开发区（8079 向下）/ 部署区（8080 向上）——两区可同时运行。

## 数据目录

正式实例持久区：`%LOCALAPPDATA%\CatHome4\Data`

| 子目录 | 内容 |
|:--|:--|
| `config/` | 配置群——全局 / 每猫默认 / 界面 / 搜索 / 视觉 / 浏览器 / QQ / 受控根表 |
| `secrets/` | 密钥——LLM 端点与密钥、QQ 凭据（**不进对话、不进快照**） |
| `sessions/` | 每猫一个目录——会话前文、视图层、该猫配置 |
| `runs/` | 每次运行一个目录——日志、工单轨迹、错误、状态快照 |
| `qqbot-files/` | QQ 通道文件缓存 |

**数据位置三级：** `CH4_DATA_ROOT` 环境变量 → 仓库根 `Data/`（就地开发隔离区）→ `%LOCALAPPDATA%\CatHome4\Data`（正式持久区）。正式实例的数据恒在第三级——仓库怎么折腾都不丢。

## 观测（出问题回看每一步）

| 文件（`runs/<时间戳>/`） | 内容 |
|:--|:--|
| `log_all.txt` | 全量时序（主文件） |
| `oa_all.txt` | 工单时序——审计帧号（post→claim→complete→unregister 断在哪一帧） |
| `err_all.txt` | 只收错误（**排查第一入口**） |
| `frame.txt` | 连续快照（250ms 一行） |

- 分级：INFO / WARN / ERR。trace 类只留内存（可查、不落盘）。
- HTTP 查询：`GET /api/v1/logs?n=&type=`。
- **帧号差 = 执行耗时**：`T_*Exec` 帧 − `T_*Args` 帧 ≈ 耗时 / 50ms——帧差大 = 主循环在推进，帧差 1-2 = 同步阻塞。

## CLI 通道（脚本化）

| 参数 | 用途 |
|:--|:--|
| 无参 | 常驻交互 |
| `--run "指令"` | 单指令脚本模式（主线程直执 + 进程自退） |
| `--script <file>` | 指令文件批量模式 |
| `--selfcheck` | 启动自检 |
| `--probe-llm <目标>` | LLM 返回体探针 |

**非交互输出双写落盘**（WinExe 无控制台 stdout）——`runs/cmd_<时间戳>.txt`，落点是**该实例自己的数据根**。

## 部署

**一键链（图形界面）：** 双击仓库根 `SetUp.exe` → 环境检测 → `prepare`（构建 → 测试 → 编译语料 → 发布）→ `deploy <仓库外目录>`。

🔴 **必须部署到仓库之外**——部署目录是正式运行实体，与仓库解耦。

**命令行等价：**

```
SetUp.exe prepare                  ← 仓库内重建（宿主照常运行）
SetUp.exe deploy C:\MauTest\MauOut ← 发布正式运行实体到仓库外
```

**前端资源轻量通道：** 改 `html/**` 后 `mau-setup mode=sync-html`（源区 → 产物区 + 运行区镜像同步）——刷新即生效，不走全链、不重启。

## 更新与重启

改完源码后：

1. **仓库内 prepare**——重编 + 刷新产物（宿主照常运行，不全频阻塞）。
2. **重启**——经特权链（仅管理面可发起）：

| 档 | 判据 | 版本 | 阻塞 |
|:--|:--|:--|:--|
| `restart-full` | 版本自增发布 / 全链保底 / 仓库内 prepare 不可行 | 自增 | ~70s |
| `restart-incr` | **默认**——产物已 prepare 就绪 | 不变 | ~10s |
| `restart-host` | 无编译无覆盖——仅重启进程（配置面变更 / 异常恢复） | 不变 | ~10s |

**默认：** 仓库内 `prepare` + `restart-incr`。重启前置零停机；**验证不过则保持在原版本运行**（天然回退）。

## 配置写入通道

`Data` 受控根只读——写配置经 `POST /api/v1/config`，或经管理面的配置工具（`config-set` / `config-cat-set`）。`schema.json` 新增项须手工补行（存量文件不落新项，缺项时写入被拒）。
